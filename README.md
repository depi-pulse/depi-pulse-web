# DEPI Pulse: Python prototype

The monitoring portal of the Ministry of Communications and IT (MCIT) for the **Digital Egypt Pioneers Initiative (DEPI)**, rebuilt in **Python / Django**.

> ⚠️ **This is a prototype, and all of its data is fake.** Every name, national ID, phone number and e-mail is generated by `seed_demo`. No real personal data is included.

## What is it?
A single place where the Ministry follows the whole training round:
- applicants and students
- groups
- training companies
- instructors
- attendance from Microsoft Teams
- the WhatsApp inbox, where the Ministry reads and replies from inside the site
- complaints
- graduation projects

Data comes in from Excel, 3 Google Forms, WhatsApp through n8n and AI, and Teams.

| Part | Technology |
|---|---|
| Server | Django 5.2 LTS (Python) |
| Interface | Django Templates + HTMX + Alpine.js, the approved prototype design (Arabic RTL, light/dark) |
| Charts | Apache ECharts |
| Data | SQLite in the prototype · PostgreSQL 18 in the real system |
| Real system (not included in the prototype) | Celery + Redis, Django Ninja API for n8n, Microsoft Entra ID, Microsoft Graph |

## Run it in one click on GitHub (Codespaces)
1. Open the repo on GitHub and click **Code**, then **Codespaces**, then **Create codespace on main**.
2. Wait two or three minutes. The libraries install, the fake data loads, and the site opens in a new tab on its own.
3. Click **«الدخول بحساب Microsoft»** (sign in with Microsoft), and you're in.

## Run it on your computer
You need Python 3.11 or newer.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows   (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Then open http://localhost:8000.

### Or with Docker
```bash
docker compose up --build
```

## Pages
| Page | Link | What's in it |
|---|---|---|
| Sign in | `/login` | Microsoft sign-in (simulated in the prototype) |
| Overview | `/` | 8 KPIs, applicant funnel, tracks, governorates, data freshness, "needs attention" |
| Students | `/students` | Search, filters, warnings per the attendance policy, and the 360° student profile |
| Companies | `/providers` | Technical, English, soft skills and consortia, with each company's details |
| Groups | `/groups` | Decoded group code, fill level, lectures, students |
| Instructors | `/instructors` | The official code `DEPI-NNNN-XXXX-XXXX-C`, approval status, review flags |
| Attendance | `/attendance` | Teams lectures, instructor lateness, missing reports, and each student's join/leave timeline |
| WhatsApp inbox | `/inbox` | Conversations, AI classification, replies, form links, the 24-hour window and templates |
| Complaints | `/tickets` | Kanban board, SLA, and changing a status notifies the sender |
| Graduation projects | `/projects` | Teams, GitHub links, scores, discussion recordings |
| Forms | `/forms` | The 3 forms: links, columns, responses |
| Excel import | `/imports` | Upload → check → differences → confirm |
| Audit log | `/audit` | Every action, including every reveal of personal data |
| Settings | `/settings` | Attendance policy, SLA, WhatsApp templates, the two AI options, integrations |
